# Loan Default Prediction using Quantitative Research

### (J.P. Morgan Chase & Co. Virtual Experience - Forage)

---

## Project Overview

This project is based on a real-world job simulation by J.P. Morgan Chase & Co., where quantitative research techniques were used to analyze loan data and predict customer default risk.

---

## Objective

* Estimate the Probability of Default (PD) for customers
* Analyze financial and credit-related data
* Convert FICO scores into risk categories

---

## Tools & Technologies

* Python
* Pandas
* NumPy
* Jupyter Notebook

---

## Dataset

* Customer Loan Dataset containing borrower financial and credit information

---

## Key Tasks Performed

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Loan Default Risk Analysis
* FICO Score Transformation
* Feature Engineering

---

## Key Insights

* Identified high-risk customers based on credit behavior
* Converted FICO scores into risk categories
* Improved default prediction understanding

---

## Methodology

* Applied quantitative research techniques
* Analyzed loan portfolio data
* Used dynamic programming for FICO categorization

---

## How to Run

1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Open Jupyter Notebook
